# Anonymized native runtime transcript

Anonymized derivative of captured macOS accessibility output from two freshly built native app bundles. It is not an untouched transcript or a synthetic rendering. Original screenshots, accessibility captures, and receipts remain local and are not published. Dates are consistently aliased as Day A–G. Actual request counts, token counts, and monetary amounts are withheld. N_A–N_G are symbolic aliases for the same independently verified known daily counts, not replacement numeric values. Source K is the countable OpenCodex history; Source U is the native Codex sample whose request counts are unavailable.
