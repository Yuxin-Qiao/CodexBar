# Session-performance component previews

Candidate source commit: `864db64a7bb168c22d8c65bd1a235c79927b3d15`.

These PNGs are generated by the repository's existing SwiftUI `ImageRenderer` test fixture with synthetic session, project, model, token, cost and timing values. They contain no real account history. Public copies omit EXIF and textual metadata; their encoded PNG image data is unchanged and the original local renders are retained.

The previews show production session-row components, the existing privacy variant and unchanged performance-detail components. They are not screenshots of an installed app and do not establish live account behavior or frame rate.

- `session-wide-light.png`: English, light appearance, 736pt component width, 2x rendering scale.
- `session-compact-dark.png`: English, dark appearance, 440pt component width, 2x rendering scale.

The candidate exposes existing cached-input reuse and sample coverage in the session metric strip. Existing details and the model/effort table remain unchanged apart from removing the duplicate cached-input detail.

The complete local render matrix additionally covered Simplified Chinese and both appearances at both widths. The source PR contains only the view and regression-test changes; these evidence files are stored on a separate fork branch.
